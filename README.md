## Release Notes

- Added an accessible in-app `Report a bug` form. Users can submit a description directly from atube without a GitHub account or configured email client.
- Bug reports include basic application and system metadata but exclude logs, file paths, cookies, account data, API keys, and video titles.
- Added local cooldown and duplicate-report protection, with additional rate limiting on the receiving service.
- Fixed imported and locally subscribed channels being lost after restarting the application.
